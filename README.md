# Social-Battery-Planner

Project topic: Social battery planner

Social Battery Planner is a mobile app that helps users keep track of their social battery.
It allows users to keep track of their social battery and to log upcoming events.
The app offers insights that are dynamically created from journal entries and social battery logging.


Team members and their areas:

1. hh6261 - general screens (such as homepage, log in, profile)
2. mk8763 - check-in screens (such as quick check-in)
3. RL3805 - insights and planner (such as scheduling and tracking events)


Technology stack:

App framework - Expo (React Native) + TypeScript + Expo Router
Running the app - Expo Go (iOS or Android)
Database - expo-sqlite
External REST API - Open-Meteo, called with fetch
Translations - i18next + react-i18next + expo-localization
Team workflow - GitHub
Accessibility Testing - TalkBack (Android) and VoiceOver (iOS), contrast checking (such as WebAIM)
Catching hardcoded text - ESLint with eslint-plugin-i18next
